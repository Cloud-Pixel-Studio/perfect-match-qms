# Changelog

- Added an operational ISO 9001:2026 customer transition playbook routing new implementation, 2015 transition, legacy migration, recertification, scope expansion, multi-site, integrated-system, and partial-implementation scenarios through controlled assessment, actions, independent reviews, migration package, execution, reconciliation, and closeout. Separates PMQMS software upgrades from QMS edition transitions; no customer migration is executed.

It records external work only and does not read or migrate customer records.
