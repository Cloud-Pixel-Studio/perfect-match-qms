# PLANS.md

Large features require an implementation plan before coding.

## Plan Template

- Objective.
- Business requirement.
- Technical approach.
- Components affected.
- Database changes.
- Security implications.
- Dependencies.
- Testing strategy.
- Acceptance criteria.
- Rollback considerations.

## Execution Rules

Do not code large features before the plan is accepted. Link implementation work to a Plane work item once Plane API access is configured. Document major decisions as ADRs.
