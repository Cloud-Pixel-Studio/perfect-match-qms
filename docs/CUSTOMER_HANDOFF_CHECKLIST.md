# Customer Handoff Checklist

- Customer name:
- Instance slug:
- Customer domain:
- Perfect Match release/tag:
- Deployment manifest/source SHA:
- License ID and edition:
- Company limit / site limit / named-user limit:
- Operational company created:
- Quality Manager created:
- Quality Manager is not Odoo System Administrator:
- Initial Sites created within entitlement:
- HTTPS and HTTP redirect validated:
- Database manager and selector not publicly exposed:
- Health check passed:
- Backup created and SHA-256 verified:
- Restore validation completed:
- Customer-ready status:
- Handoff date/operator:

Never put passwords, API keys, private signing keys, activation request
contents, or customer secrets in this checklist.
