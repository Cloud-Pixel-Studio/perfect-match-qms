# ISO 9001:2026 Implementation and Transition Scenarios

This catalog defines Perfect Match QMS implementation scenarios. It is
proprietary PMQMS workflow metadata and does not reproduce ISO publication text.

## Supported scenarios

| Code | Scenario | Source | Target |
| --- | --- | --- | --- |
| ISO9001-2026-INITIAL | New implementation | None | 2026 |
| ISO9001-2026-TRANSITION-2015 | Transition | 2015 | 2026 |
| ISO9001-2026-LEGACY | Legacy or incomplete migration | Legacy | 2026 |
| ISO9001-2026-RECERTIFICATION | Recertification | 2015 | 2026 |
| ISO9001-2026-SCOPE-EXPANSION | Scope expansion | Existing scope | 2026 |
| ISO9001-2026-MULTI-SITE | Multi-site rollout | Existing scope | 2026 |
| ISO9001-2026-INTEGRATED | Integrated management system | Separate profiles | 2026 |
| ISO9001-2026-PARTIAL | Partial implementation | Declared scope | 2026 |

## Operating rules

- The 2015 and 2026 profile records coexist.
- Existing 2015 tasks, evidence, assessments, audits, and management reviews
  remain historical records.
- A transition creates a new implementation baseline; it does not rewrite the
  prior baseline.
- Legacy data must be inventoried and classified before migration.
- Missing or unverified evidence remains open until the normal QMS workflow
  accepts it.
- Multi-site evidence remains traceable to its site.
- Integrated-system scenarios keep each standard profile and evidence boundary
  independent.
- Partial implementation records its exclusions and cannot be presented as
  complete certification readiness.
- The application reports internal implementation readiness only; it does not
  grant or replace certification.

## ISO source boundary

The licensed ISO 9001:2026 publication is used by authorized reviewers to
confirm external references and transition interpretation. The repository
stores only edition metadata, reference identifiers approved through review,
and PMQMS-authored controls and workflow definitions.
