# Oliva Torras Onboarding Checklist

Use this checklist when Oliva authorizes real onboarding work.

## Authorization

- [ ] Customer sponsor identified.
- [ ] Customer implementation owner identified.
- [ ] Written authorization received for each migration data source.
- [ ] Data classification and confidentiality expectations confirmed.
- [ ] Migration scope approved.
- [ ] External mapping scope approved, if applicable.

## Users And Access

- [ ] User list received.
- [ ] Roles assigned: QMS User, QMS Manager, QMS Administrator.
- [ ] User email addresses verified.
- [ ] Access tested with least privilege.
- [ ] Other-company access isolation verified.

## Processes

- [ ] Process inventory received.
- [ ] Process owners assigned.
- [ ] Process codes agreed.
- [ ] Process descriptions approved by customer.
- [ ] Generated control instances reviewed against processes.

## Documents

- [ ] Document inventory received in approved CSV format.
- [ ] Current revision for each document identified.
- [ ] Owner login values verified.
- [ ] Process codes verified.
- [ ] Control instance codes verified.
- [ ] Attachments approved for import.
- [ ] Import results reviewed.

## Evidence

- [ ] Evidence inventory received in approved CSV format.
- [ ] Evidence requirement names verified against generated controls.
- [ ] Document links verified.
- [ ] Attachments approved for import.
- [ ] Evidence imported without `accepted` state.
- [ ] Evidence reviewed and accepted through QMS workflow.

## Operational Data

- [ ] Current risk register authorized for entry or import.
- [ ] Current NCR list authorized for entry or import.
- [ ] Current CAPA list authorized for entry or import.
- [ ] Current audit program and findings authorized for entry or import.
- [ ] KPI definitions and targets authorized.
- [ ] Customer and supplier performance data authorized.
- [ ] Management review schedule and participants approved.

## Readiness

- [ ] Initial customer readiness assessment run.
- [ ] Gaps reviewed with customer owner.
- [ ] Evidence gaps assigned.
- [ ] Task completion reviewed.
- [ ] Not-applicable controls justified.
- [ ] Final readiness assessment reviewed.
- [ ] Go-live decision documented without certification claims.
